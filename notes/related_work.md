## Serving systems and KV memory

### kwon2023paged - PagedAttention/vLLM: paged KV-cache memory management for LLM serving
- **Retrieval:** arXiv eprint 2309.06180 -> `data/raw/literature/arxiv_2309.06180.xml` (verified via arxiv-api)
- **Supports:** The retrieved abstract states that per-request KV-cache memory is huge and grows and shrinks dynamically, that fragmentation and redundant duplication limit batch size, and that PagedAttention/vLLM reaches near-zero KV-cache waste with flexible sharing. It directly supports the premise that KV memory, not parameter count, is the binding constraint in LLM serving.
- **Fits:** Related work (serving systems); Introduction motivation

### zhong2024distserve - DistServe: prefill/decoding disaggregation driven by KV-cache duplication
- **Retrieval:** arXiv eprint 2401.09670 -> `data/raw/literature/arxiv_2401.09670.xml` (verified via arxiv-api)
- **Supports:** The abstract documents disaggregating prefill and decoding onto different GPUs and co-optimizing per-phase resource allocation for TTFT/TPOT goodput. It supports discussing KV-cache placement/duplication as a first-class concern in serving systems.
- **Fits:** Related work (serving systems)

## Attention kernels

### dao2022flashattention - FlashAttention: IO-aware exact attention
- **Retrieval:** arXiv eprint 2205.14135 -> `data/raw/literature/arxiv_2205.14135.xml` (verified via arxiv-api)
- **Supports:** The abstract argues attention is IO-bound between GPU HBM and SRAM and proposes tiling to cut memory reads/writes, with linear memory instead of quadratic. It grounds the kernel-level view of attention memory traffic as distinct from KV-cache capacity.
- **Fits:** Related work (attention kernels)

### dao2023flashattention2 - FlashAttention-2: parallelism and work partitioning
- **Retrieval:** arXiv eprint 2307.08691 -> `data/raw/literature/arxiv_2307.08691.xml` (verified via arxiv-api)
- **Supports:** The abstract reports better work partitioning across thread blocks/warps and roughly 2x speedup over FlashAttention, reaching 50-73% of theoretical FLOPs/s on A100. Background for attention efficiency at long context.
- **Fits:** Related work (attention kernels)

## KV-head reduction

### shazeer2019mqa - Multi-Query Attention (one shared KV head)
- **Retrieval:** arXiv eprint 1911.02150 -> `data/raw/literature/arxiv_1911.02150.xml` (verified via arxiv-api)
- **Supports:** The abstract attributes slow incremental decoding to the memory-bandwidth cost of repeatedly loading keys and values, and proposes sharing one KV head across query heads with only minor quality loss. It is the origin of KV-head reduction (MQA).
- **Fits:** Related work (KV-head reduction)

### ainslie2023gqa - Grouped-Query Attention
- **Retrieval:** arXiv eprint 2305.13245 -> `data/raw/literature/arxiv_2305.13245.xml` (verified via arxiv-api)
- **Supports:** The abstract introduces grouped-query attention, an intermediate number of KV heads between MHA and MQA, uptrained from multi-head checkpoints with about 5% of original pre-training compute at near-MHA quality. It is the mechanism behind the census variation in GQA ratio.
- **Fits:** Related work (KV-head reduction); RQ2 mechanisms

### deepseekai2024v2 - DeepSeek-V2: Multi-head Latent Attention (MLA) + MoE
- **Retrieval:** arXiv eprint 2405.04434 -> `data/raw/literature/arxiv_2405.04434.xml` (verified via arxiv-api)
- **Supports:** The abstract reports a 236B-total/21B-active MoE whose Multi-head Latent Attention compresses the KV cache into a latent vector, with a 93.3% KV-cache reduction and up to 5.76x generation throughput versus DeepSeek 67B. It is the canonical MLA reference and also documents the MoE/KV interaction.
- **Fits:** Related work (KV-head reduction, MoE); RQ2/RQ3 discussion

## Attention scope and sinks

- **Supports:** The abstract describes Mistral 7B combining grouped-query attention with sliding-window attention to handle sequences of arbitrary length at reduced inference cost. It anchors the gqa+swa architecture class in the census.

### xiao2023streamingllm - StreamingLLM: attention sinks, fixed-memory streaming attention

## KV compression

### zhang2023h2o - H2O: heavy-hitter KV eviction
- **Retrieval:** arXiv eprint 2306.14048 -> `data/raw/literature/arxiv_2306.14048.xml` (verified via arxiv-api)
- **Supports:** The abstract frames KV eviction as dynamically retaining a balance of recent tokens and 'heavy hitters' (a small set of tokens contributing most attention value), with throughput gains up to 29x over leading inference systems. Representative KV-eviction baseline.
- **Fits:** Related work (KV compression)

### liu2024kivi - KIVI: 2-bit KV-cache quantization
- **Retrieval:** arXiv eprint 2402.02750 -> `data/raw/literature/arxiv_2402.02750.xml` (verified via arxiv-api)
- **Supports:** The abstract studies KV element distributions (keys quantized per-channel, values per-token) and derives a tuning-free 2-bit KV quantization giving 2.6x lower peak memory and up to about 4x larger batch. It grounds the KV-precision axis of the capacity model.
- **Fits:** Related work (KV quantization); RQ3 methods

### hooper2024kvquant - KVQuant: 4-bit KV-cache quantization for long context
- **Retrieval:** arXiv eprint 2401.18079 -> `data/raw/literature/arxiv_2401.18079.xml` (verified via arxiv-api)
- **Supports:** The abstract reports 3-bit KV quantization with under 0.1 perplexity degradation, enabling 1M-token LLaMA-7B inference on one A100-80GB. It supports the low-KV-precision scenarios in the capacity analysis.
- **Fits:** Related work (KV quantization); RQ3

### chang2024palu - Palu: low-rank KV-cache compression
- **Retrieval:** arXiv eprint 2407.21118 -> `data/raw/literature/arxiv_2407.21118.xml` (verified via arxiv-api)
- **Supports:** The abstract proposes low-rank projection of the linear layers, caching compressed intermediate states and reconstructing keys and values on the fly, compressing the KV cache by about 50% while maintaining accuracy. It is the low-rank KV-compression representative.
- **Fits:** Related work (KV compression)

## Cross-layer KV sharing

### sun2024yoco - YOCO: decoder-decoder with one shared cross-layer KV cache
- **Retrieval:** arXiv eprint 2405.05254 -> `data/raw/literature/arxiv_2405.05254.xml` (verified via arxiv-api)
- **Supports:** The abstract introduces a decoder-decoder architecture (YOCO) that caches key-value pairs only once and reuses the global KV cache across layers via cross-attention, reporting large memory, prefill-latency and throughput gains and extension to 1M context. It is the cross-layer shared-KV architecture the census labels as KV-shared.
- **Fits:** Related work (cross-layer KV sharing)

### wu2024cla - CLA: layer-condensed KV cache (bottom-layer-only KV)
- **Retrieval:** arXiv eprint 2405.10637 -> `data/raw/literature/arxiv_2405.10637.xml` (verified via arxiv-api)
- **Supports:** The abstract computes and caches KV for only a small number of layers, reporting up to 26x higher throughput with competitive quality, and notes orthogonality to other memory-saving techniques. Second cross-layer KV-sharing design.
- **Fits:** Related work (cross-layer KV sharing)

## Long-context scaling

### su2021roformer - RoFormer: rotary position embeddings (RoPE)
- **Retrieval:** arXiv eprint 2104.09864 -> `data/raw/literature/arxiv_2104.09864.xml` (verified via arxiv-api)
- **Supports:** The abstract proposes rotary position embedding (RoPE), encoding absolute positions with a rotation matrix while incorporating relative position dependencies, with flexible sequence length. It is the position mechanism that long-context census models extend.
- **Fits:** Methods (long-context scaling background)

### peng2023yarn - YaRN: NTK-aware context-window extension
- **Retrieval:** arXiv eprint 2309.00071 -> `data/raw/literature/arxiv_2309.00071.xml` (verified via arxiv-api)
- **Supports:** The abstract presents YaRN, a compute-efficient RoPE-based context-window extension requiring 10x fewer tokens and 2.5x fewer training steps than prior methods, letting LLaMA models use much longer contexts. Context for why declared context lengths grew over the census window.
- **Fits:** Methods (long-context scaling); RQ1 discussion

## Linear attention

### katharopoulos2020linear - Linear transformers with fixed-size state (Katharopoulos et al.)
- **Retrieval:** arXiv eprint 2006.16236 -> `data/raw/literature/arxiv_2006.16236.xml` (verified via arxiv-api)
- **Supports:** The abstract rewrites self-attention as a linear dot-product of kernel feature maps, reducing complexity from quadratic to linear and enabling an iterative RNN-like implementation that is up to 4000x faster on long autoregressive prediction. It is the origin of constant-state linear attention.
- **Fits:** Related work (linear attention); KV accounting for recurrent layers

### sun2023retnet - RetNet: retention, parallel/recurrent modes
- **Retrieval:** arXiv eprint 2307.08621 -> `data/raw/literature/arxiv_2307.08621.xml` (verified via arxiv-api)
- **Supports:** The abstract derives the retention mechanism with parallel, recurrent, and chunkwise paradigms, where the recurrent form gives O(1) inference cost with improved GPU memory. Another constant-state attention family relevant to fixed-state KV accounting.
- **Fits:** Related work (linear attention)

### peng2023rwkv - RWKV: RNN with transformer-scale training
- **Retrieval:** arXiv eprint 2305.13048 -> `data/raw/literature/arxiv_2305.13048.xml` (verified via arxiv-api)
- **Supports:** The abstract presents RWKV, which combines parallelizable transformer training with constant-memory RNN inference and scales to 14B parameters, performing on par with similarly sized transformers. It is the open-weight recurrent family included in the census.
- **Fits:** Related work (linear attention); family context

### yang2024gdn - Gated DeltaNet: gated delta-rule linear attention
- **Retrieval:** arXiv eprint 2412.06464 -> `data/raw/literature/arxiv_2412.06464.xml` (verified via arxiv-api)
- **Supports:** The abstract combines gating for adaptive memory control with the delta rule for targeted updates (Gated DeltaNet), outperforming Mamba2 and DeltaNet, and builds hybrids with sliding-window attention or Mamba2 layers. A modern fixed-state linear-attention design used by recent models.
- **Fits:** Related work (linear attention)

## State-space models and hybrids

- **Supports:** The abstract makes SSM parameters input-dependent (selective state spaces) with a hardware-aware recurrent algorithm, reporting 5x higher inference throughput than Transformers and linear scaling in sequence length. It is the fixed-state recurrent class the census accounts for as constant KV-independent state.
- **Fits:** Related work (SSMs); Methods (recurrent-layer state accounting)

### de2024griffin - Griffin: gated linear recurrences + local attention (Hawk/Griffin)

- **Supports:** The abstract proposes Hawk (gated linear recurrences) and Griffin (mixing gated linear recurrences with local attention), matching Llama-2 quality with lower inference latency and higher throughput and extrapolating beyond training lengths. Canonical hybrid of recurrent and windowed attention.
- **Fits:** Related work (SSM hybrids)

### lieber2024jamba - Jamba: Transformer-Mamba hybrid MoE

- **Supports:** The abstract describes Jamba, an open-weight hybrid that interleaves Transformer and Mamba layers with MoE, fitting in a single 80GB GPU and supporting 256K-token contexts with smaller memory footprint than vanilla Transformers. An open-weight hybrid MoE family in the census.
- **Fits:** Related work (SSM hybrids); family context

### zuo2025falcon - Falcon-H1 (fallback chain: Falcon-H1 -> Falcon Mamba -> Zamba): parallel-SSM hybrid
